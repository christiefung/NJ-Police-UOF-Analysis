# # New Jersey Use of Force Analysis Dashboard

An interactive Shiny dashboard analyzing police use of force incidents across New Jersey counties, standardized by population data.

## Live Demo
https://3iwmjz-christie-fung.shinyapps.io/nj-police-uof-analysis/

## Features
* **Interactive Map:** Visualize standardized force levels (Hands/Fists, Pepper Spray, Deadly Force, etc.) by county.
* **Standardized Metrics:** Data is calculated as incidents per 100,000 residents to ensure fair comparisons between counties.
* **County Filtering:** Toggle specific counties to compare regional trends.

## Built With
* **R / Shiny** - Dashboard framework
* **ggplot2 & sf** - Spatial data visualization
* **Tigris** - US Census Bureau shapefiles
* **Tidyverse** - Data manipulation
